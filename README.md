# 🚀 RealXR Club – 3D Web Experience

An interactive 3D web experience built using **Three.js** that visualizes key concepts of **AR, VR, and XR** in a dynamic space environment.

---

## 🌌 Live Demo
👉 https://your-live-link.vercel.app

---

## 📌 Project Overview

This project is designed as a futuristic **XR-inspired web interface** where users can explore a virtual 3D space filled with floating concepts like:

- Virtual Reality  
- Augmented Reality  
- Metaverse  
- Simulation  
- Innovation  

The goal is to simulate a **cinematic and immersive environment** similar to AR/VR experiences using web technologies.

---

## ✨ Features

- 🧠 3D Text Rendering using Three.js  
- 🌌 Particle-based Space Background  
- 🚀 Words floating in 3D space  
- 🎬 Cinematic Camera Movement  
- 🔄 Z-depth animation (objects move toward user)  
- ✨ Glow animation using emissive materials  
- 🎮 Interactive Controls:
  - Change color of text
  - Scale objects  
- 🖱️ OrbitControls for user interaction  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript  
- Three.js  
- OrbitControls  
- FontLoader & TextGeometry
