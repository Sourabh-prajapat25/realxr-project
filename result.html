RealXR Club Web Experience

📌 Project Overview

This project is a 3D web-based interactive experience built using Three.js. It represents a futuristic AR/VR environment where concepts related to Extended Reality (XR) are visualized in a dynamic 3D space.

✨ Features Implemented

  • 3D text rendered using Three.js
  • Floating XR-related keywords in space
  • Particle-based space background
  • Z-depth animation (objects moving toward user)
  • Glow animation using emissive materials
  • Cinematic camera movement
  • Interactive controls (color & scaling)

🧠 Technologies Used

  • HTML, CSS, JavaScript
  • Three.js (3D rendering)
  • OrbitControls (camera interaction)
  • FontLoader & TextGeometry

🎯 Concept

The goal of this project is to simulate an immersive XR-like interface where users feel like they are inside a digital space. The floating words represent key concepts of AR/VR such as Virtual Reality, Metaverse, and Simulation.
